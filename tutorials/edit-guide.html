一、网站文件结构

文件/文件夹作用
index.html首页目录（打开这个就是主页）
pages\75个AI单页（每个AI一个html文件）
assets\css\main.css全站样式（颜色、大小、玻璃效果）
assets\js\main.js全站功能（客服面板、搜索、B站解析）
assets\img\所有图片（二维码、截图）
search-engine-sdk\万能搜索接口（可单独提取使用）
tutorials\图文教程页面

二、如何修改网站内容

1. 修改文字内容

1打开index.html

用记事本或浏览器右键→"用记事本打开" index.html

2找到要改的文字

按Ctrl+F搜索关键词，直接修改文字，保存

3刷新预览

双击index.html在浏览器中打开，按F5刷新看效果

2. 修改颜色/样式

打开 assets\css\main.css，找到对应项修改：

常用颜色变量css
/* 主金色 - 改成你喜欢的颜色 */
:root {
  --gold: #d4a017;       /* 主色 */
  --gold-light: #f4d03f; /* 亮色 */
  --bg: #fef9e7;         /* 背景色 */
  --text: #333;          /* 文字颜色 */
}

/* 客服面板8个按钮颜色 */
.svc-link.c1 { background: linear-gradient(135deg,#ff6b6b,#ee5a6f); }
.svc-link.c2 { background: linear-gradient(135deg,#48dbfb,#0abde3); }
.svc-link.c3 { background: linear-gradient(135deg,#ff9ff3,#f368e0); }
.svc-link.c4 { background: linear-gradient(135deg,#54a0ff,#5f27cd); }

3. 增加新的AI页面

1复制一个现有页面

打开 pages\ 文件夹，复制任意一个html文件，改名为 新AI名.html

2编辑内容

用记事本打开新文件，把里面的AI名称、介绍、链接改成新AI的信息

3在首页添加卡片

打开 index.html，按Ctrl+F找到分类卡片区域，复制一张卡片代码，修改名称和链接：

卡片HTML模板html
<a class="card" href="pages/新AI名.html">
  <div class="card-ico">🤖</div>
  <h3>新AI名称</h3>
  <p>一句话简介</p>
  <div class="card-tag">分类标签</div>
</a>

4. 修改客服面板链接

打开 index.html，按Ctrl+F搜索 svc-link，找到8个按钮的标签，修改href：

修改按钮链接html
<!-- 快手小店按钮 -->
<a class="svc-link c1" href="你的新链接" target="_blank">
  <span class="svc-ico">🛒</span>快手小店
</a>

三、如何上传修改到网站

方法A：用GitHub网页上传（最简单）

1打开仓库网页

访问 github.com/ss1319/ai-directory

2点Add file → Upload files

把改好的文件拖进去，点Commit changes

3等1分钟

GitHub Pages自动更新，刷新网站即可看到新内容

方法B：用GitHub Desktop上传

1打开GitHub Desktop

打开你电脑上的GitHub Desktop 3.5.4

2File → Add Local Repository

选择文件夹 E:\000000已设计好的完整HTML源码\AI配置教程

3点Commit to main

左下角写修改说明，点Commit

4点Push origin

右上角点Push，等几秒上传完成

四、万能搜索引擎接口提取

搜索接口文件在 search-engine-sdk\ 文件夹：

文件用途
search-api.js搜索功能核心代码（纯英文）
search.css搜索界面样式

嵌入到其他网页：把这两个文件复制到你的项目，在HTML中引入：

嵌入到任意网页html
<link rel="stylesheet" href="search.css">
<input id="ss-input" type="search" placeholder="搜索...">
<button id="ss-go">搜索</button>
<div id="ss-results"></div>
<div id="ss-player"></div>
<script src="search-api.js"></script>

五、常见问题

Q：改完文件网站没变化？
A：按Ctrl+F强制刷新，等1分钟GitHub Pages自动更新。

Q：图片不显示？
A：检查图片路径是否正确，HTML中引用用相对路径如 assets/img/xxx.png

Q：想加新分类？
A：在index.html中复制一个分类标题和卡片区域，改分类名即可。

注意：不要删除 .git 文件夹（隐藏文件夹），它是Git版本管理用的。不要删除 assets\ 文件夹，全站样式都在里面。
