📖 平台详细介绍

Kimi是月之暗面（Moonshot AI）公司开发的AI智能助手，由前旷视科技首席科学家杨植麟创立。Kimi最大的特色是超长文本处理能力，支持一次性处理200万字的超长文本，这意味着用户可以上传一整本长篇小说、数百页的PDF文档、完整的代码库、几千页的学术论文，Kimi都能同时理解并回答相关问题。这个超长上下文窗口在行业内处于领先水平，使其成为处理长文档的首选AI工具。 Kimi支持多种文件格式上传，包括PDF、Word、PPT、Excel、TXT、CSV等，还支持直接粘贴网页链接，Kimi会自动抓取网页内容并进行总结。Kimi的联网搜索功能可以获取实时信息，当用户问"今天天气如何"或"最新的新闻"时，Kimi会自动搜索并给出答案。Kimi还内置了代码解释器，可以直接运行Python代码进行数据分析、图表生成、数学计算等操作，特别适合处理数据和写代码。 月之暗面公司成立于2023年，是国内大模型创业公司中的头部企业。Kimi在iOS和Android都有App，也有网页版。Kimi开放平台提供API服务，支持8K/32K/128K/200K四种上下文长度的模型，开发者可以根据需求选择不同规格。Kimi的API兼容OpenAI格式，迁移成本低。Kimi还支持创建智能体，用户可以定制专属AI助手，如论文阅读助手、代码审查助手等。

💡 主要用途

  • 超长文档阅读与总结（200万字）
  • 整本书阅读与问答
  • 完整代码项目分析
  • 合同/法律文书审查
  • 联网搜索获取最新信息
  • 数据分析与可视化
  • 多文档对比分析
  • 论文阅读总结
  • 翻译长文档
  • 网页内容提取总结

🚀 详细使用步骤

1第一步：访问 kimi.moonshot.cn 或下载Kimi App
2第二步：使用手机号注册登录
3第三步：点击左下角+号上传文件或直接粘贴长文本
4第四步：在对话框输入问题开始对话
5第五步：点击顶部搜索图标开启联网搜索模式
6第六步：可以创建智能体自定义专属助手
7第七步：API开发访问 platform.moonshot.cn

🔌 API回调函数代码

// Kimi API调用示例（兼容OpenAI SDK格式）
// 官网: https://platform.moonshot.cn

from openai import OpenAI
client = OpenAI(
    api_key="YOUR_MOONSHOT_KEY",
    base_url="https://api.moonshot.cn/v1"
)
# 长文本对话（128K上下文）
resp = client.chat.completions.create(
    model="moonshot-v1-128k",
    messages=[
        {"role": "system", "content": "你是文档分析助手"},
        {"role": "user", "content": "请总结这个文档的主要内容"}
    ],
    temperature=0.3
)
print(resp.choices[0].message.content)

// 文件上传并分析：
files = client.files.create(file=open("document.pdf", "rb"), purpose="file-extract")
