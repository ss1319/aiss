📖 平台详细介绍

OpenAI是全球最知名的人工智能公司，开发了GPT（Generative Pre-trained Transformer）系列大语言模型。GPT-4o是最新一代多模态模型，支持文字、图片、语音的理解和生成，能够实时语音对话，识别图片内容。OpenAI API是全球使用最广泛的AI接口，几乎所有主流AI应用（如ChatGPT、Cursor、Notion AI等）都基于GPT模型构建。它支持函数调用（Function Calling）、结构化输出、JSON模式、流式输出等高级功能，是开发者构建AI应用的首选。OpenAI还提供嵌入向量（Embeddings）API，用于文本相似度计算和RAG检索。GPT-4o支持128K上下文窗口，可以处理长文档。ChatGPT Plus订阅用户可以使用GPT-4o和DALL-E图片生成、Code Interpreter等功能。

💡 主要用途

  • GPT模型API调用
  • 函数调用Function Calling
  • 多模态图片理解
  • 代码生成与调试
  • 内容创作与写作
  • Agent构建与工具使用
  • 嵌入向量Embeddings
  • 文本摘要与翻译
  • 聊天机器人开发
  • RAG知识库检索

🚀 详细使用步骤

1第一步：访问 platform.openai.com 注册OpenAI账号
2第二步：完成手机验证和邮箱验证
3第三步：在API Keys页面创建API Key，妥善保存
4第四步：充值账户额度（最低5美元）
5第五步：安装SDK npm install openai
6第六步：编写代码调用chat.completions接口
7第七步：在Usage页面查看用量和费用

🔌 API回调函数代码

// OpenAI API完整调用示例
// 官网: https://platform.openai.com

// JavaScript:
import OpenAI from "openai";
const openai = new OpenAI({apiKey: "YOUR_OPENAI_KEY"});

// 1. 基础对话
const resp = await openai.chat.completions.create({
  model: "gpt-4o",
  messages: [
    {role: "system", content: "你是专业助手"},
    {role: "user", content: "你好"}
  ],
  temperature: 0.7,
  max_tokens: 2000
});
console.log(resp.choices[0].message.content);

// 2. 函数调用
const resp2 = await openai.chat.completions.create({
  model: "gpt-4o",
  messages: [{role: "user", content: "北京天气怎么样"}],
  tools: [{
    type: "function",
    function: {
      name: "get_weather",
      description: "获取天气",
      parameters: {type: "object", properties: {city: {type: "string"}}}
    }
  }]
});

// Python:
from openai import OpenAI
client = OpenAI(api_key="YOUR_KEY")
resp = client.chat.completions.create(
  model="gpt-4o",
  messages=[{"role": "user", "content": "你好"}]
)
