MCP协议

离线/本地部署类
🚀 立即访问MCP协议

📖 平台详细介绍

MCP（Model Context Protocol）是Anthropic推出的开放协议，标准化了AI模型与外部工具/数据源的连接方式。通过MCP，AI可以访问文件系统、数据库、API等外部资源。

💡 主要用途

  • 标准工具协议
  • AI连接外部资源
  • 文件系统访问
  • 数据库连接
  • 插件生态
  • 跨模型通用

🚀 详细使用步骤

1第一步：访问modelcontextprotocol.io了解协议
2第二步：安装MCP SDK（pip install mcp）
3第三步：配置MCP Server（如文件系统Server）
4第四步：在Claude Desktop等客户端配置mcp.json
5第五步：重启客户端生效
6第六步：AI即可访问本地文件和工具

🔌 API回调函数代码

// MCP Server示例代码
// 文件: server.py
from mcp import Server
server = Server("my-server")

@server.tool()
def read_file(path: str) -> str:
    """读取文件内容"""
    with open(path, "r") as f:
        return f.read()

server.run()

// Claude Desktop配置 (~/Library/Application Support/Claude/claude_desktop_config.json)
{
  "mcpServers": {
    "filesystem": {
      "command": "python",
      "args": ["/path/to/server.py"]
    }
  }
}
